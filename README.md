# ☕ Cafena Coffee Landing Page

Landing page moderna para uma cafeteria fictícia chamada **Cafena Café**, desenvolvida com foco em design responsivo, experiência do usuário e layout elegante.

🔗 **Acesse o projeto:**  
https://nataliapastre-dev.github.io/cafena-coffee-landing-page/

---

## 📌 Sobre o projeto

O **Cafena Coffee Landing Page** é um site institucional de cafeteria com seções bem estruturadas:

- Home com destaque principal
- Sobre a cafeteria
- Menu de produtos
- Avaliações de clientes
- Localização com mapa
- Footer com redes sociais

---

## 🚀 Tecnologias usadas

- HTML5  
- CSS3  
- JavaScript  
- Google Fonts  
- Google Maps Embed  

---

## 💻 Funcionalidades

- Layout responsivo (mobile e desktop)
- Menu hambúrguer no mobile
- Animações suaves
- Seções organizadas e modernas
- Mapa integrado do Google Maps
- Botões interativos

---

## 📱 Responsividade

O site se adapta para:

- 📱 Celulares  
- 📟 Tablets  
- 💻 Desktop
